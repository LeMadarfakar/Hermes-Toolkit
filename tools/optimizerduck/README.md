# optimizerDuck — Free Windows Optimization Tool

## Overview
optimizerDuck is a free, open-source Windows optimization tool focused on performance, privacy, and simplicity. Portable, no installation required.

## Download
- **Latest**: [GitHub Releases v2.29.0](https://github.com/itsfatduck/optimizerDuck/releases/tag/v2.29.0)

- **SHA256**: Check releases page

## What It Does
| Category | Tweaks |
|----------|--------|
| **Performance** | Service host tuning, process priority, keyboard latency, multimedia scheduler |
| **Privacy** | Telemetry disable, data collection blocking, Cortana removal |
| **Gaming** | GPU scheduling, foreground boost, game mode, input latency |
| **Bloatware** | AppX package removal (Safe/Caution/Unknown ratings) |
| **Services** | 200+ Windows services startup management |
| **Startup** | Startup program manager with risk ratings |
| **Disk Cleanup** | Temp files, logs, caches, old updates |
| **GPU** | AMD/NVIDIA/Intel specific registry tweaks |

## Usage
1. **Download** `optimizerDuck.exe` from [GitHub Releases](https://github.com/itsfatduck/optimizerDuck/releases)
2. **Right-click → Run as Administrator** (required for system changes)
3. **Create restore point** when prompted
4. **Browse categories**, read descriptions & risk ratings (Safe/Caution/Unknown)
5. **Toggle desired tweaks** → **Apply** → **Restart PC**

## Safety
- **Creates automatic restore point** before changes
- **One-click revert** for any applied tweak
- **Risk ratings** on every tweak (Safe/Caution/Unknown)
- **No installation** — portable single .exe
- **Open source** (GPL-3.0)

## What It Does NOT Do
- ❌ Remove viruses/trojans/malware
- ❌ Real-time protection
- ❌ Replace antivirus
